# Memory 0.3.1 变更说明

状态：正式交付候选，尚未发布。

相对已公开的 0.3.0-cordis.0，支持官方 Harness 0.1.5-rc.2 / Cordis 4.0.2：显式匹配目标 peer 版本，替换已移除的 Client runtime 依赖，沿用独立 Core 与现有可选 Brain 关系。补齐默认捕获、维护、召回和卸载重装的确定性官方 Profile 验证。

本次从 R7 提交 ee9142d791e324ab0f77007de9186f4018b88251 切换到独立版本 0.3.1，仅改变版本身份、说明和产物校验路径；运行时、数据库 schema、默认设置均不变。此前同名内部候选不是已公开 Release 的字节，不得覆盖原资产。

0.3.1 包的运行时文件与 R7 包逐字节比较；沿用 R7 的 19 项定向测试、12 次 loopback 请求及安装/卸载/恢复证据，不将这些旧哈希报告直接改名冒充新运行。新增身份、包对应与严格声明检查记录于 dist/release-0.3.1，并显式指向所沿用证据。

实际已验收 Intel macOS / Node 25.6.0 与精确官方 npm 包；无 Brain 不自动召回。真实 UI、其他平台与最终桌面组合仍待相应验收。最终是否发布由总指挥决定。
